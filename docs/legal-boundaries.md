# Legal Boundaries

This repository is for original research, documentation, and clean-room tooling around ICO for PlayStation 2.

It must not contain:

- ICO ISO files
- executable files extracted from the game
- extracted models, textures, audio, video, maps, scripts, cutscenes, or other assets
- copied proprietary source code
- decompiled code copied from commercial binaries as source
- patches that embed copyrighted game data
- instructions intended to bypass ownership of the original game

Future tooling should require contributors to provide their own legally obtained local copy of the game.

## Allowed Content

The repository may contain:

- original documentation
- original scripts and tooling
- offsets, sizes, hashes, file names, and structural descriptions
- synthetic fixtures created specifically for tests
- clean-room parsers and validators
- notes that describe behavior without redistributing copyrighted content

## Contribution Review

Pull requests should be rejected or revised if they include proprietary data, extracted game content, or unclear ownership. When in doubt, contributors should describe how an observation was produced instead of uploading the observed copyrighted material.
